# 🏦 Logos dos Bancos e Cartões de Crédito

Coloque os arquivos de imagem (**`.png`**, **`.svg`** ou **`.webp`**) nesta pasta (`public/logos/bancos/`).

O sistema do Kapitou identifica o banco automaticamente pelo nome do arquivo.

### 💡 Dicas para melhor visualização:
1. **Resolução:** Imagens quadradas transparentes (ex: `128x128` ou `256x256` pixels).
2. **Fundo:** PNG com fundo transparente ou com o ícone centralizado.
3. **Fallback Automático:** Caso você ainda não tenha colocado a imagem de algum banco, o sistema exibirá automaticamente a logo vetorial oficial nativa do sistema.
