# Kit de Marca & Logos Oficiais da Kapitou

Este diretório contém todas as variações vetoriais (.SVG em altíssima resolução) para uso em materiais de marketing, apresentações, redes sociais, impressos e desenvolvimento web.

---

## 🎨 Paleta de Cores Oficial

| Cor | Hex Code | Uso |
| :--- | :--- | :--- |
| **Emerald Primary** | `#10B981` | Cor principal da marca, destaques, botões e símbolo |
| **Emerald Light** | `#34D399` | Gradientes, brilhos (*glows*) e hover |
| **Teal Secondary** | `#14B8A6` | Gradiente complementar de sofisticação |
| **Dark Background** | `#08090C` | Fundo oficial Dark Mode |
| **Dark Pure** | `#000000` | Fundo preto puro |
| **White Pure** | `#FFFFFF` | Textos em destaque e fundos claros |

## 📁 Arquivos Disponíveis

### 1. Símbolos Isolados (Ícone)
* `kapitou-symbol-emerald.svg`: Símbolo verde esmeralda com fundo transparente.
* `kapitou-symbol-white.svg`: Símbolo branco com fundo transparente.
* `kapitou-symbol-black.svg`: Símbolo preto com fundo transparente.
* `kapitou-symbol-dark-bg.svg`: Símbolo verde em card arredondado escuro (`#08090C`).
* `kapitou-symbol-white-bg.svg`: Símbolo verde em card arredondado branco (`#FFFFFF`).
* `kapitou-symbol-green-bg.svg`: Símbolo branco em card arredondado verde (`#10B981`).

### 2. Logos Horizontais (Símbolo + Nome "KAPITOU")
* `kapitou-horizontal-emerald-transparent.svg`: Símbolo verde + texto branco (fundo transparente).
* `kapitou-horizontal-white-transparent.svg`: Logo completa em branco puro (fundo transparente).
* `kapitou-horizontal-black-transparent.svg`: Logo completa em preto puro (fundo transparente).
* `kapitou-horizontal-dark-bg.svg`: Logo completa em fundo escuro (`#08090C`).
* `kapitou-horizontal-white-bg.svg`: Símbolo verde + texto preto em fundo branco (`#FFFFFF`).
* `kapitou-horizontal-green-bg.svg`: Logo completa em branco em fundo verde esmeralda (`#10B981`).

### 3. Logos Verticais / Selos (Símbolo Acima + Nome Abaixo)
* `kapitou-vertical-dark-bg.svg`: Logo vertical centralizada em fundo escuro.
* `kapitou-vertical-white-bg.svg`: Logo vertical centralizada em fundo branco.
* `kapitou-vertical-green-bg.svg`: Logo vertical centralizada em fundo verde esmeralda.

## 🚀 Como Visualizar ou Baixar no Navegador

Como esses arquivos estão dentro da pasta pública (`/public/logos`), você pode acessá-los e baixá-los diretamente digitando a URL no navegador, por exemplo:
* `http://127.0.0.1:3000/logos/kapitou-horizontal-dark-bg.svg`
* `http://127.0.0.1:3000/logos/kapitou-symbol-emerald.svg`
* `http://127.0.0.1:3000/logos/kapitou-symbol-white-bg.svg`
* `http://127.0.0.1:3000/logos/kapitou-horizontal-green-bg.svg`
